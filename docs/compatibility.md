# 兼容性

版本 0.1.0 的真实 agy 调用仅支持已验证的 **macOS arm64 + Antigravity CLI 1.5.8**。其他平台或 agy 版本返回 `ISOLATION_UNVERIFIED`，由宿主按失败规则处理。Node.js 最低版本为 22.12，验证使用 Node.js 22.23.3。

CI 在 Ubuntu、macOS 和 Windows 上分别运行测试、构建与发行包校验，各平台独立完成检查。路径测试使用本机路径格式，并验证目录链接不能使制品路径越过授权目录；Windows 使用目录 junction，其他平台使用符号链接。

Windows 会跳过依赖 POSIX 可执行脚本夹具的 ACP 调用与授权、部分能力探测及原生驱动测试。**CI 通过仅代表已执行的测试范围通过，不扩大上述真实 agy 调用的支持范围。** Windows 和 Linux 的真实调用仍需分别完成隔离、授权和进程回收验收后才能开放。

| 宿主 | 已验证的能力 | 当前限制 |
| --- | --- | --- |
| Codex CLI 0.169.0 | 插件解析、MCP 加载、润色、搜索、失败返回及会话授权转接协议 | 安装后的技能菜单和人工授权操作尚未验证 |
| Cursor CLI 2026.11.11-043ef28、2026.11.13-eacade1 | `--plugin-dir` 加载、健康检查、润色、搜索、失败不重试；非交互模式拒绝待授权写入且不落文件 | 交互式允许、取消和授权超时尚未验证。2026.11.13 上默认 30 秒润色预算超时；显式传入代理并把润色预算调到 60000 后完成 |
| Codex 桌面 | 提供对应发行包 | 图形界面中的加载、菜单和授权操作尚未验证 |
| Cursor 编辑器 3.30.8 | 本地插件目录可被发现，MCP 进程能拉起试用启动脚本 | 编辑器会话中的健康检查、搜索、技能菜单，以及人工允许、拒绝、取消和授权超时尚未确认。发行包里的 `node` 命令尚未在图形界面单独验证 |

Codex 解析的完整技能名称为 `agy-connector-plugin:agy`、`agy-connector-plugin:agy-polish`、`agy-connector-plugin:agy-websearch`。短名称和斜杠菜单以宿主实际显示为准。插件解析成功不代表所有图形界面交互都已得到支持。

若终端中的 agy 可用，而宿主中持续超时，请检查 MCP 是否取得了所需代理变量。默认 30 秒润色预算也可能不足，可按 [使用说明](usage.md) 调整；失败不会自动重试。

CLI 升级后需要重新验证隔离适配，不能仅修改版本判断开启调用。权限边界及结果可靠性见 [验证范围与使用限制](verification.md)。
