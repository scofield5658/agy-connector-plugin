# 使用说明

## 三种能力

**中文润色**针对生成或修改的中文文档，以及聊天中明确要求撰写的长文。宿主先准备底稿，再把必要上下文交给 agy。插件保护代码、链接、占位符等内容；事实、语气和确定程度仍需宿主复核。原稿发生变化时，不采用旧候选。

**网页搜索**仅在用户指定时调用。独立临时空间只开放 `search_web` 和结果提交，不开放本地文件、Shell 或 MCP。结果包含实际查询、答案和来源；来源可能是 Google 跳转链接，重要结论需核对原页面。域名列表是检索偏好，不是网络访问白名单。

**通用委托**在宿主实际项目目录运行，沿用明确的读写范围和制品目录，使用 agy 自有配置与工具。无需复制工作区或搬运制品。目录声明和路径校验不等于操作系统沙箱，不能保证任意 Shell、MCP 或启动 hook 都受目录限制；只委托本任务已授权的操作。

所有模式只发送必要且允许外部处理的材料。禁止外发的资料不进入 agy。润色和搜索使用私有临时配置；通用委托可能使用、更新 agy 自身会话状态。插件不自动安装、升级 CLI 或改动全局权限。

## 授权与失败

原生操作需要确认时，通过宿主 MCP 表单展示工具、参数和路径，由用户选择“仅本次允许”或“拒绝”。宿主可能先询问是否调用 MCP 工具，再询问具体原生操作。模型不能代为批准，也不能通过参数传入批准结果。审批占用任务总预算。

| 情况 | 后续处理 |
| --- | --- |
| 润色不可用、超时或结果不合格 | 保留原稿，继续文档工作 |
| 搜索失败 | 报告原因；允许替代供应方时由宿主自行搜索 |
| 通用委托失败 | 先检查已有文件或外部副作用，再在原授权内接手；不声称已回滚 |
| 用户指定必须由 agy 完成 | 明确报告指定委托未完成，不用宿主结果冒充 |
| 用户拒绝、取消、授权过期或授权界面不可用 | 停止本次委托，不接手同一被拒绝操作 |

任何失败都不自动重试、不换 requestId 绕过失败。每个任务最多两轮；反馈沿用原模式、目录和授权，总预算不重置。扩大范围需要新的明确授权。

## 环境配置

[README](../README.md) 提供构建和安装命令。使用发行包无需 pnpm 或源码依赖；Codex 与 Cursor 的包不能互换。GUI 找不到 Node 时，在自己的 MCP 配置中将 `command` 改成本机 Node 绝对路径。

| 环境变量 | 默认 | 范围 |
| --- | --- | --- |
| `AGY_EXECUTABLE` | 查找本地 `agy` | 可指定绝对路径；显式路径错误不回退 |
| `AGY_POLISH_BUDGET_MS` | 30000 | 5000–60000 |
| `AGY_SEARCH_BUDGET_MS` | 60000 | 5000–60000 |
| `AGY_NATIVE_BUDGET_MS` | 120000 | 5000–300000 |
| `AGY_GENERAL_BUDGET_MS` | 60000 | 5000–60000，仅兼容文本委托 |
| `AGY_MAX_TURNS` | 2 | 1 或 2，含初次调用 |
| `AGY_CHINESE_RATIO` | 0.5 | 0–1，自动润色的中文比例阈值 |

由宿主 MCP 配置传入这些变量，修改后重启 MCP。预算包含审批、反馈等待和进程清理；默认 30 秒可能不足，可将润色预算设为 60000。插件不读取项目任意配置文件或保存凭据。

**代理配置：**宿主通常不会把整个终端环境传给 MCP。若终端中 agy 可用、宿主中却一直超时，在该 MCP 的 `env` 中显式设置本机需要的 `http_proxy`、`https_proxy`、`all_proxy`（或对应大写变量）及 `no_proxy`。只传实际使用的变量，不复制整个环境，不把代理凭据写入仓库。Cursor 支持 `${env:变量名}` 插值；Codex 自建 MCP 配置支持 `env_vars` 选择性继承。GUI 启动的宿主也需要能取得这些变量。

首次可调用 `agy_health`：`ready` 和 `modes` 表示版本、隔离适配和配置检查结果，`auth=unknown`；它不调用模型，不验证登录、网络或配额。

| 常见原因 | 处理 |
| --- | --- |
| `CLI_UNAVAILABLE` | 检查 agy 安装路径 |
| `ISOLATION_UNVERIFIED` | 查看 [已验证组合](compatibility.md)，不绕过隔离门槛 |
| `AUTH_REQUIRED` | 检查官方登录状态；首次登录不是任务内操作审批 |
| `DEADLINE_EXCEEDED` | 本次按规则降级；检查网络及后续任务预算 |
| `CONTENT_REJECTED` | 候选改变了受保护内容，保留原稿 |
| `AUTHORIZATION_UNAVAILABLE` / `AUTHORIZATION_EXPIRED` | 授权界面不可用或等待授权超时，停止本次委托 |
| `INSTANCE_DISABLED` | 先前进程回收未确认，检查后重启插件 |

## 卸载与数据

临时 `--plugin-dir` 会话退出即停止加载；已安装副本通过宿主插件管理界面移除。不会卸载 agy 或删除其登录态。

请求记录仅在 MCP 内存中，空闲 15 分钟过期；私有临时空间在退出、失效或正常清理时删除。原生委托写入的制品及 agy 自身历史不随插件卸载删除。无法确认子进程已回收时保留现场并停止启动新调用。
