# 验证范围与使用限制

以下范围对应版本 0.1.0，验证日期为 2026-11-14。具体系统和宿主版本见 [兼容性](compatibility.md)。

## 已验证范围

| 能力 | 验证范围 |
| --- | --- |
| 中文润色 | 传入文稿、受保护内容检查、候选反馈及超时保留原稿 |
| 网页搜索 | 实际调用 agy 搜索，返回查询、答案和来源；缺少搜索执行证据时拒绝成功结果 |
| 通用委托 | 在共享测试目录生成制品，检查路径范围和文件存在性 |
| 操作授权 | 协议层的仅本次允许、拒绝、取消、授权过期及迟到响应处理；未覆盖真实 GUI 人工操作 |
| 模式隔离 | 润色和搜索使用私有配置，全局及插件来源的启动 hook/MCP 有正、负对照验证 |
| 失败与回收 | 请求去重、总预算、并发限制、取消和进程回收；无法确认回收时停止新调用 |
| 发行包 | Codex/Cursor 包独立运行、包含空格和中文的路径、缺少 agy 时的降级 |

## 使用限制

**润色结果仍需复核。** 自动检查保护代码、链接和占位符等内容，不能证明事实、语气和确定程度正确。12 个虚构样本中，11 个返回候选、1 个超时；这个小样本不构成质量或响应时间保证。

**搜索链接需要核验。** agy 的 [官方工具说明](https://antigravity.google/docs/sdk/tools/) 将 `search_web` 标为 Google Search。插件确认搜索已实际执行，但来源由模型汇总，不能保证每条链接都支持对应结论，也不承诺搜索质量优于其他工具。

**目录声明不是完整沙箱。** 原生委托使用 agy 自有配置、MCP、Skills 和 hooks。路径检查不能限制任意 Shell、外部 MCP 或启动扩展的全部行为，也不复制宿主的操作系统沙箱。应只委托本任务已授权的操作。

**失败不代表回滚。** 原生委托可能已写入部分文件或影响外部系统。宿主接手前应检查当前状态；用户拒绝、取消或授权过期的操作不能由宿主绕过执行。无法确认进程回收时，应先处理残留进程再重启插件。

**图形界面支持尚未完整验证。** Codex 桌面和 Cursor 编辑器的技能菜单、人工授权及取消，以及 Cursor CLI 的交互式授权，仍属于未验证范围。协议模拟通过不代表这些界面操作已通过验证。

配置、错误处理及卸载方式见 [使用说明](usage.md)。
