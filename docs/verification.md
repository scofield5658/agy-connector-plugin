隔离测试发现：**仅设置 Agent 的继承开关仍会提前启动全局 MCP**。最终实现同时使用请求私有配置，并通过独立配置正对照、OS 访问保护下的负对照验证。没有覆盖所有未来 CLI 版本或任意恶意二进制；升级需重新验证。

搜索官方工具说明为 [Google Search](https://antigravity.google/docs/sdk/tools/)。本次查询结果与 [Node.js 官方发布页](https://nodejs.org/en/blog/release/v22.12.0) 一致；CLI 事件证明执行过搜索，不证明模型汇总的每条链接都支持结论，也不代表搜索质量优于其他模型。

显式运行以下命令会联网并消耗模型额度：

```sh
pnpm verify:isolation
pnpm verify:modes
pnpm evaluate:agy
```

前两项使用独立配置、正负对照或合成文件；`verify:modes` 的批准由受限测试客户端模拟，不是替真实用户默认批准。报告写入 Git 忽略的 `.local/`；发行包不携带日志、配置或凭据。宿主启动时所需的代理由测试实例显式传入，不复制整个环境。

## 中文质量样本

当前私有配置下的 12 个虚构样本：11 个返回候选，1 个（proposal）超时；候选耗时 14.3–24.6 秒。逐句对照未发现新增事实、确定程度升级或受保护内容损坏。这个小样本不构成质量或时延保证，润色后仍需语义复核。

示例：

- 原稿：“本月可用率达到了99.9%，相比上月有所提升，具体提升幅度还需要确认。”
- 候选：“本月可用率达99.9%，较上月有所提升，具体提升幅度待确认。”

测试还包含否定、预计语气、技术术语、代码、链接、占位符、frontmatter 和待定信息，输入保存在 `tests/fixtures/documents/samples.json`。历史调试结果不与当前样本混算。

## 验收缺口

Codex/Cursor CLI 的润色、搜索及降级已实测；Codex 插件安装验收仅到原生解析和临时 MCP 运行。GUI 自动化连接重试仍超时，因此桌面/编辑器菜单、人工批准与取消仍待补验。Cursor 交互式授权同样未覆盖。具体版本见 [兼容性](compatibility.md)。

生产已有全局 agy MCP/插件组合、任意 Shell 或外部系统副作用未做破坏性测试。原生目录声明是任务授权范围，不是完整强制沙箱；失败后必须检查已有状态。

## 换机继续

接续分支：`feat/initial-connector`。源码与锁定依赖已随提交保存；`dist/`、`release/`、`.local/` 和 `.superpowers/` 不进入 Git，在新机器重新构建即可。

1. 准备 Node.js ≥22.12、pnpm 10.33.0 和本机已登录的 agy，按 [README](../README.md) 安装依赖、验证和构建。真实调用仍仅启用已验证的 macOS arm64 + agy 1.5.8；其他系统可继续开发与运行模拟测试，不绕过隔离门槛。
2. 在独立宿主配置和测试项目中加载对应发行包，按 [使用说明](usage.md) 配置该机器需要的代理。登录态、代理凭据和本机路径不随 Git 迁移。
3. 补验 Codex 桌面、Cursor 编辑器及 Cursor 交互 CLI：三个技能入口、health、润色、搜索，以及原生委托的本次允许、拒绝、取消和授权超时。
4. 原生测试仅使用虚构文件；核对未批准时不写入、制品位于共享目录、取消后进程回收，以及宿主未接手被拒绝操作。把结果更新到本记录，不能将现有协议测试等同于人工 GUI 验收。
